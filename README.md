# ナリユキワールド

AI住民たちと暮らす、成り行きまかせの町シミュレーション（ブラウザゲーム）。

あなたは町にやってきた「よそ者」。そしてこの町の住民の中には、ひとり**人狼**がまぎれています。働いて仲良く暮らすのも、盗んで殴ってのし上がるのも、口先で住民を操るのも自由です。住民たちは自分で考え、噂し、掲示板に書き込み、ときに裏切ります。15日後、町はどうなっているでしょうか。

### スマホで遊ぶ（縦画面OK）

- スマホのブラウザで開くと、自動でスマホ用の画面になります。
- **移動**：画面のどこでもなぞるとスティックが出ます（倒し具合で速さが変わる）。
- **話す・調べる**：右下の丸ボタン（近くにあるものに合わせて「話す」「入る・使う」などに変わる）。
- **人の近くで建物を使う**：丸ボタンの上の青いボタン（例：食堂の中で人の隣にいても「食堂」で働く・食べるができる）。
- 体力・満腹度・所持金・食料は右上にいつも表示されます。
- 走るのは、指を輪の外まで大きく引っぱったときだけ。
- **拡大・縮小**：2本指でピンチ。🗺ボタンで地図の表示切替。
- 状態・持ち物・手帳・住民・掲示板・記録は、下のタブで開け閉めします（掲示板に新しい書き込みがあると赤い点）。
- スマホでは「ブラウザ内AI」は使えません。「クラウドAI」か「AIなし」で遊べます。
- ホーム画面に追加すると「ナリユキ」という名前のアプリとして起動できます（iPhone：共有 →「ホーム画面に追加」／Android：メニュー →「ホーム画面に追加」）。

### クラウドAIの無料枠

- Workers AI の無料枠は1日 10,000 ニューロン（毎朝9時・日本時間にリセット）。
- 使用量の目安は「状態」パネルの「住民の頭脳」と、画面左上（50%を超えると ☁️〇% と表示）で確認できます。
- 使い切ると、PC（WebGPUあり）はブラウザ内AIに、スマホはAIなしに切り替わります。AIなしで作った返事には会話画面で「📜 AIなし」の印がつき、左上に「📜AIなし（無料枠切れ）」と出ます。朝9時を過ぎると自動でクラウドAIに戻ります。
- 目安（初期設定の Llama 3.3 70B）：住民への話しかけ1回で約30ニューロン、1日でおよそ300回ぶん。普通に遊んで1日1.5〜3時間くらい。環境変数 AI_MODEL を安いモデル（例：@cf/qwen/qwen3-30b-a3b-fp8）にすると数倍長く遊べますが、日本語の自然さは下がるかもしれません。

- 建物にはそのまま歩いて入れます（入ると屋根が外れて中が見える）。住民も中で働き、食べ、眠ります。
- 住民に近づいて F → 話す／「一緒に来て」と頼む／お金や物を渡す／殴る／盗む／脅す
- 建物の中で F → 食べる・働く・転職・鍛える・治療・通報・物色 など
- 町の南東の🏡があなたの家。ベッドで寝られて、タンスにお金をしまえば盗まれない。
- 会話中は相手が立ち止まる。会話画面の「渡す」ボタンや「3Gあげるから一緒に来て」「花束どうぞ」「食べ物売って」で物やお金をやり取りできる。住民はもらった物を覚えていて、好物（住民タブで確認）だととても喜ぶ。手配中に欲深い衛兵へお金を渡すと見逃してもらえることも。
- 転職は、その職場で働いている住民に頼む（建物の中でF、または会話で「雇ってください」）。働く・鍛えるあいだは時間が早送りになり、頭の上に進み具合が出る。
- 会話は自由入力。「食堂に行こうよ」「おごるよ」「〇〇ってどんな人？」「研究所はどこ？」「何してるの？」などの意味を読み取って返事し、誘いに乗ると実際についてきます。
- 掲示板には誰でも書き込めます。住民の名前を出すと噂になり、町の人間関係が動きます。
- 夜は自分の家（右下の🏡）か酒場で寝ましょう。毎朝、生活費が2Gかかります。
- 2日目に空から「光る石」が落ちてきます。研究所で2時間調べると正体がわかります。
- 盗みを重ねると「盗みの腕」が上がり、見つかりにくくなります（状態パネルで確認）。住民が寝ている家なら、腕しだいでこっそり物色できます。
- 誰かの悪事（盗み・乱暴など）を聞いたら、住民と相談できます。「どうするべき？」と聞くと、住民は自分の考えを言ってから「衛兵に知らせる？ 話し合う？ 様子を見る？」と聞き返してくるので、好きなものを選べます（「様子を見よう」「やっぱりいいや」でやめられる）。「会議でもする？」のような軽い提案には「集まってもらう？」と確認してくれ、「ツヅミの処遇を決めよう」「話し合おう」とはっきり頼むとすぐに**処遇の話し合い**が開かれます。話し合いでは目撃者や被害者が証言し、「牢屋に1日／罰金5G／許す」を投票で決めます。
- 「広場で待ってて」「ここで待ってて」と頼むと、その場所で2時間ほど待ってくれます（来てくれたら一緒に過ごす）。時間を決めるなら「3時に広場で会おう」。

## 人狼（決まった進行のない、自由型）

- 住民10人のうち1人が人狼（毎回ランダム）。夜中に本当に家を抜け出し、歩いて誰かの家へ行って襲います。夜ふかししていれば、出歩く姿を目撃できることも。
- 朝、誰かが遺体を見つけて初めて事件が広まります。現場（襲われた家の中でF）には足あと、同じ家の住民には「夜中に〇〇が出ていく物音を聞いた」などの手がかりが残ります。
- 住民は一人ひとり「誰を疑っているか」を持っていて、噂話で疑いが広がります。人狼は嘘をつき、他人に罪をなすりつけます。
- 話し合いは決まった時間には開かれません。住民か、あなた（会話で「話し合おう」、掲示板でF、掲示板への書き込み）が呼びかけたときに、広場の噴水の前に人が集まって話し合い、投票で牢屋に入れる人を決めます。衛兵が独断で怪しい人を捕まえることもあります。
- 牢屋の人が人狼なら真夜中に正体を現し、無実なら次の事件で釈放されます。何もしなくても町は勝手に動き、人狼が勝つこともあります。
- 聞き込みの例：「昨日の夜どこにいた？」「〇〇は昨日の夜どこにいた？」「人狼は誰だと思う？」「〇〇が人狼だと思う」「〇〇が夜中に出歩いてるのを見た」

## 人狼を追いつめる・倒す

- 現場（襲われた家の中でF）を調べると、足あとの行き先に加えて**獣の毛**が見つかる。毛の色は人狼の髪の色と同じ。住民に近づくと髪の色が見える（帽子の人は「〇〇の髪の色は？」と聞く。人狼は自分の髪の色をごまかす）。
- 人狼騒ぎのあとは、他人の家を無断で調べられる。人狼の家なら**血のついた服**が見つかる。
- 証拠を持って告発すると、よそ者でも信じてもらいやすい（話し合いでも一対一でも）。
- 工房で鍛冶屋に**銀のナイフ**（25G）を作ってもらうと、人狼を倒せる。普通の攻撃では人狼は死なない。正体がばれた人狼は夜に牢屋を破ることがある。
- 人狼の疑いで牢屋にいる人は保釈できない。衛兵か村長に「〇〇を釈放して」と頼むか、逃がすしかない。

## セーブ

- 画面右下の💾でセーブ、🏠でタイトルへ。毎朝オートセーブされ、タイトル画面の「つづきから」で再開できる（ブラウザ内に保存）。

## 村長・税金・町の決まり

- 村長のゲンジが町のまとめ役。毎朝、税金（はじめは1日4G）を集めて町の金庫に入れる。払えないと滞納になり、2日分たまると手配される（役場で払える）。
- 村長は金庫のお金で町の食料を買い足し、困っている人が増えると配給や減税を提案する。人狼騒ぎでは懸賞金を出す。
- 町の決まりは話し合いの投票で変わる。村長に頼む、話し合いの場で言う、掲示板に書く、のどれかで提案できる。
  例：「夜間外出禁止にしよう」「税金を下げよう」「見回りを増やそう」「食料を配給しよう」「武器を禁止しよう」
  住民は性格や立場で賛成・反対する（欲深い人は増税に反対、人狼は夜間外出禁止に反対、など）。話し合いの場では、投票の前に意見を言って説得でき、あなたも賛成・反対の一票を入れられる。
- 牢屋の住民とは鉄格子ごしに話せる。保釈金を払う／鍵をこじ開けて逃がす（犯罪）ことができ、「出してやろうか？」と取引を持ちかけるとお金や秘密の情報と引き換えにできる。
- 市場・食堂・酒場・工房・役場の金庫でも盗みができる（見られると手配）。
- 住民が持っている物は会話で売り買いできる。「光る石を売って」「10Gで譲って」→ 相手が値段を言い、「20Gでどう？」と値切れる。まとまれば本当に物とお金が入れ替わる。盗まれた物やお金は「返して」と言える。

## 生きている町

- 住民の方から話しかけてきます（噂・頼みごと・食事の誘い・食べ物のおねだり・話し合いへの呼びかけ・文句・夜の警告など）。画面下に出たらFで返事。頼みごと（〇〇を持ってきて）を果たすとお礼がもらえます。
- すれ違うとひとこと声をかけられます。
- 会話で頼んだことは住民が本当に実行し、あとで結果を報告しに来ます（好感度や性格によっては断られます）。
  - 「〇〇を通報して」「通報したほうがいいかな？」→ 詰所へ伝えに行き、〇〇が手配される
  - 「今夜〇〇を見張って」→ 夜中に〇〇の家の前で見張り、朝に「出てこなかった／出ていった」と報告
  - 「〇〇のことみんなに言いふらして」→ 何人かに噂を広める
  - 「〇〇を懲らしめて」→ 気の荒い住民なら殴りに行く
  - 「18時に酒場で会おう」→ その時間にその場所で待っている（すっぽかすと嫌われる）
- 一緒に行こうと誘うと、相手はあなたについて来て（案内役なら先に立って待ちながら）、着いたら隣の席で一緒に飲み食いしながら話します。

## 住民の頭脳（タイトル画面で選択）

| モード | 内容 |
|---|---|
| クラウドAI（おすすめ） | Cloudflare Workers AI を使う。PCに負担なし。無料プランなら料金はかからず、その日の無料枠を使い切ると自動で「ブラウザ内AI」に切り替わる |
| ブラウザ内AI | [WebLLM](https://github.com/mlc-ai/web-llm) で Qwen2.5-7B を自分のPCのGPUで動かす。約5GB。GPUメモリ8GB以上推奨。PC版Chrome（WebGPU）必須 |
| AIなし | すぐ遊べる。言葉の意味（誘う・頼む・質問・噂など）を読み取り、住民ごとの口調で返事する |

会話の仕組み：まずゲーム側が「相手が何を言ったか」「誘いを受けるか・断るか」などを決め、内容が決まった返事は手書きのセリフを使います。AIは答えの決まっていない雑談に使い、的外れな出力や崩れた日本語は自動でゲーム側のセリフに差し替えます。

## 公開方法（Cloudflare Pages）

ビルド不要の静的サイトです。

1. Cloudflare ダッシュボード → Workers & Pages → 作成 → Pages → このリポジトリを接続
2. ビルドコマンド：なし ／ 出力ディレクトリ：`/`
3. クラウドAIを使う場合：Pages プロジェクトの 設定 → バインディング → Workers AI を追加（変数名 `AI`）。`functions/api/chat.js` が自動で有効になります。使うモデルは環境変数 `AI_MODEL` で変更できます（既定は `@cf/meta/llama-3.3-70b-instruct-fp8-fast`）。

タイトル画面の「最新版に更新」ボタンで、ブラウザに残った古いファイルを読み直せます。コードを変えたら `node tools/bump-version.mjs` でバージョンを上げると、タイトル画面に「新しい版があります」と表示されます。

ローカルで試す場合：`python3 -m http.server` で起動して `http://localhost:8000` を開く。

```

js/wolf.js          人狼（夜の狩り・手がかり・疑い・自由な話し合い・投票）
js/dialog.js        会話の意図の読み取りと、口調ごとのセリフ集
js/brain.js         住民の頭の中（会話の判断・LLMプロンプト・掲示板）
js/llm.js           LLMアダプタ（WebLLM / API / なし を切り替え）

```
