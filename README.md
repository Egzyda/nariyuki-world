# ナリユキワールド

AI住民たちと暮らす、成り行きまかせの町シミュレーション（ブラウザゲーム）。

あなたは町にやってきた「よそ者」。働いて仲良く暮らすのも、盗んで殴ってのし上がるのも、口先で住民を操るのも自由です。住民たちは自分で考え、噂し、掲示板に書き込み、ときに裏切ります。15日後、町はどうなっているでしょうか。

## 遊び方

| 操作 | キー |
|---|---|
| 移動 | WASD / 矢印キー（Shift で走る） |
| 話す・建物でできること・拾う | F / スペース |
| メニューの選択 | 1〜9 |
| 持ち物 | I |
| 掲示板を開く | B |
| 一時停止 | P |
| 地図の表示切替 | M |
| 拡大・縮小 | マウスホイール / − = |

- 建物にはそのまま歩いて入れます（入ると屋根が外れて中が見える）。住民も中で働き、食べ、眠ります。
- 住民に近づいて F → 話す／「一緒に来て」と頼む／お金や物を渡す／殴る／盗む／脅す
- 建物の中で F → 食べる・働く・転職・鍛える・治療・通報・物色 など
- 町の南東の🏡があなたの家。ベッドで寝られて、タンスにお金をしまえば盗まれない。
- 会話中は相手が立ち止まる。会話画面の「渡す」ボタンや「3Gあげるから一緒に来て」「花束どうぞ」「食べ物売って」で物やお金をやり取りできる。住民はもらった物を覚えていて、好物（住民タブで確認）だととても喜ぶ。手配中に欲深い衛兵へお金を渡すと見逃してもらえることも。
- 転職は、その職場で働いている住民に頼む（建物の中でF、または会話で「雇ってください」）。働く・鍛えるあいだは時間が早送りになり、頭の上に進み具合が出る。
- 会話は自由入力。「食堂に行こうよ」「おごるよ」「〇〇ってどんな人？」「研究所はどこ？」「何してるの？」などの意味を読み取って返事し、誘いに乗ると実際についてきます。
- 掲示板には誰でも書き込めます。住民の名前を出すと噂になり、町の人間関係が動きます。
- 夜は自分の家（右下の🏡）か酒場で寝ましょう。毎朝、生活費が2Gかかります。
- 2日目に空から「光る石」が落ちてきます。研究所で調べると……？

## 住民の頭脳（タイトル画面で選択）

| モード | 内容 |
|---|---|
| AIなし | すぐ遊べる。言葉の意味（誘う・頼む・質問・噂など）を読み取り、住民ごとの口調で返事する |
| ブラウザ内AI | [WebLLM](https://github.com/mlc-ai/web-llm) で、遊ぶ人のPCのGPU上でLLMを動かす。API代ゼロ。PC版Chrome推奨（WebGPU必須）。初回に約1〜5GBをダウンロード |
| クラウドAI | Cloudflare Workers AI を使う（下記の設定をした場合のみ表示） |

会話の仕組み：まずゲーム側が「相手が何を言ったか」「誘いを受けるか・断るか（空腹・仕事中・好感度・所持金などで判断）」を決め、AIはそれを住民の口調で自然に言い直すだけです。AIが的外れなことを言ったときは自動でゲーム側のセリフに差し替えるので、話がかみ合わなくなりません。

住民は全員、AIで掲示板への書き込み・1日の方針決めも行います。

## 公開方法（Cloudflare Pages）

ビルド不要の静的サイトです。

1. Cloudflare ダッシュボード → Workers & Pages → 作成 → Pages → このリポジトリを接続
2. ビルドコマンド：なし ／ 出力ディレクトリ：`/`
3. （任意）クラウドAIを使う場合：Pages プロジェクトの 設定 → バインディング → Workers AI を追加（変数名 `AI`）。`functions/api/chat.js` が自動で有効になります。使うモデルは環境変数 `AI_MODEL` で変更できます（既定は `@cf/meta/llama-3.3-70b-instruct-fp8-fast`）。

ローカルで試す場合：`python3 -m http.server` で起動して `http://localhost:8000` を開く。

## ファイル構成

```
index.html          画面
css/style.css       見た目
js/data.js          職業・施設（内装）・住民（口調・髪型）・アイテム・イベントの定義
js/state.js         ゲーム状態と共通ヘルパー
js/world.js         マップ（建物の内部・家具）・通行判定・経路探索
js/sim.js           シミュレーション本体（時間・欲求・ルールAI・同行・事件・プレイヤー行動）
js/dialog.js        会話の意図の読み取りと、口調ごとのセリフ集
js/brain.js         住民の頭の中（会話の判断・LLMプロンプト・掲示板）
js/llm.js           LLMアダプタ（WebLLM / API / なし を切り替え）
js/sprites.js       ドット絵の人物スプライト生成
js/render.js        描画（地形・内装・屋根・夜の明かり・ミニマップ）
js/main.js          起動・入力・UI
functions/api/chat.js  Cloudflare Workers AI 用のAPI
```

デバッグ用に、ブラウザのコンソールから `NW.S`（状態）と `NW.Sim`（関数）を触れます。
