# ナリユキワールド

AI住民たちと暮らす、成り行きまかせの町シミュレーション（ブラウザゲーム）。

あなたは町にやってきた「よそ者」。働いて仲良く暮らすのも、盗んで殴ってのし上がるのも、口先で住民を操るのも自由です。住民たちは自分で考え、噂し、掲示板に書き込み、ときに裏切ります。15日後、町はどうなっているでしょうか。

## 遊び方

| 操作 | キー |
|---|---|
| 移動 | WASD / 矢印キー |
| 話す・施設に入る・拾う | E / スペース |
| メニューの選択 | 1〜9 |
| 掲示板を開く | B |
| 一時停止 | P |

- 住民に近づいて E → 話す／お金や物を渡す／殴る／盗む／脅す
- 施設の入口で E → 食べる・働く・転職・鍛える・治療・通報・空き巣 など
- 掲示板には誰でも書き込めます。住民の名前を出すと噂になり、町の人間関係が動きます。
- 夜は空き家（右下）か酒場で寝ましょう。毎朝、生活費が2Gかかります。
- 2日目に空から「光る石」が落ちてきます。研究所で調べると……？

## 住民の頭脳（タイトル画面で選択）

| モード | 内容 |
|---|---|
| AIなし | すぐ遊べる。キーワードに反応するテンプレ会話 |
| ブラウザ内AI | [WebLLM](https://github.com/mlc-ai/web-llm) で、遊ぶ人のPCのGPU上でLLMを動かす。API代ゼロ。PC版Chrome推奨（WebGPU必須）。初回に約1〜2GBをダウンロード |
| クラウドAI | Cloudflare Workers AI を使う（下記の設定をした場合のみ表示） |

★マークの主要住民8人がAIで会話・掲示板への書き込み・1日の方針決めを行い、残りの12人はルールで動きます。

## 公開方法（Cloudflare Pages）

ビルド不要の静的サイトです。

1. Cloudflare ダッシュボード → Workers & Pages → 作成 → Pages → このリポジトリを接続
2. ビルドコマンド：なし ／ 出力ディレクトリ：`/`
3. （任意）クラウドAIを使う場合：Pages プロジェクトの 設定 → バインディング → Workers AI を追加（変数名 `AI`）。`functions/api/chat.js` が自動で有効になります。

ローカルで試す場合：`python3 -m http.server` で起動して `http://localhost:8000` を開く。

## ファイル構成

```
index.html          画面
css/style.css       見た目
js/data.js          職業・施設・住民・アイテム・イベントの定義（ここを増やすと町が広がる）
js/state.js         ゲーム状態と共通ヘルパー
js/world.js         マップ・通行判定・経路探索
js/sim.js           シミュレーション本体（時間・欲求・ルールAI・事件・プレイヤー行動）
js/brain.js         住民の頭の中（LLMプロンプトとテンプレ）
js/llm.js           LLMアダプタ（WebLLM / API / なし を切り替え）
js/render.js        描画
js/main.js          起動・入力・UI
functions/api/chat.js  Cloudflare Workers AI 用のAPI
```

デバッグ用に、ブラウザのコンソールから `NW.S`（状態）と `NW.Sim`（関数）を触れます。
